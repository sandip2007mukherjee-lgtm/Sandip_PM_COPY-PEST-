
# Sandip PM Copy Filter Tool

A mobile-first Excel and CSV Form Number filtering tool with an interactive glassmorphism interface.

## Features

- Filter records where Verification Status is blank.
- Filter records where Digitization Done is Yes.
- Copy each Form Number only once.
- Keep copied numbers visible and locked.
- Automatically scroll toward the next available number.
- Search Form Numbers and track progress.
- Customize colors, profile photo, and background photo.
- Responsive layout for mobile devices.

## Deployment

1. Upload `index.html` to the repository root.
2. Keep `profile.jpg` in the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch.
5. Select `main` and `/(root)`.
6. Save and open the published website.

The spreadsheet-reading library loads from a CDN, so an internet connection is required to process Excel files.
